# X Image Downloader

X(Twitter)の画像・動画を、ワンクリックで保存するブラウザ拡張機能です。画像は原寸のまま保存します。
Chrome / Edge と Firefox に対応しています。

画像・動画・GIF付きのツイートのアクションバー(いいねなどの並び)の右端に保存ボタンが出ます。

## 保存先

ブラウザのダウンロードフォルダの中に、次の形式で保存します(初期設定)。
パソコンのブラウザ向けの設定で、Androidではフォルダを指定できません(下の「スマホ(Androidなど)で保存するとき」を参照)。

```
Twitter/<年>-<月>/<ユーザーID>-<ツイートID>-<連番>.<拡張子>
例: Twitter/2026-11/username-2117123456789012345-0.jpg
```

連番は 0 から始まります。フォルダ名・ファイル名は設定画面のテンプレートで自由に変えられます。

### スマホ(Androidなど)で保存するとき

> **⚠ Androidでは、保存先のフォルダを指定できません。**
> Androidのブラウザ(Vivaldiなど)では、フォルダ名のテンプレートは使われず、ダウンロードフォルダの直下に保存されます。

フォルダの代わりに、設定画面の「フォルダの使い方」を「フォルダは作らず、フォルダ名をファイル名の前に付ける」にすると、フォルダ名がファイル名に入ります。

```
例: Twitter_2026-11_username-2117123456789012345-0.jpg
```

初期設定は「フォルダに分けて保存する」です。
フォルダ名のテンプレートを `{YYYY}-{MM}` のように短くすると、ファイル名も短くなります。

## 動画・GIFの保存

動画とGIFは、MP4ファイルで保存します。ファイル名・フォルダ名は画像と同じテンプレートに従います(`{index}` は動画だけで数えて 0 から)。

```
例: Twitter/2026-11/username-2117123456789012345-0.mp4
```

- Xのページが自分で読み込むデータから、動画ファイル(MP4)のURLを拾って保存します。Xのログイン情報には触れず、通信も増やしません。
- 動画の保存を始めたあと、ブラウザのダウンロード欄で進み具合を見られます。
- 拡張機能を入れた直後など、ページを開いたままだと動画の情報が取れていないことがあります。その場合はページを再読み込みしてからもう一度押してください。
- 引用ツイートの中の動画には対応していません(引用元のツイートを開いて保存してください)。
- MP4の配信がない動画(一部の配信形式)は保存できません。

## お知らせ

保存ボタンを押すと、画面の下に短いお知らせが出ます(スマホの画面でも1行におさまります)。

- 保存を始めたとき: `動画1本の保存を開始しました`
- 保存が終わったとき: `動画1本の保存が完了しました`(失敗したときは、その理由が出ます)

保存先のパスは、初期設定では出しません。設定画面で「お知らせに、保存先のパスも表示する」をオンにすると、お知らせの2行目に出ます。

## 設定画面

ツールバーの拡張機能アイコンを押すと開きます。変更は自動で保存されます。

| 項目 | 内容 |
| --- | --- |
| フォルダ名 / ファイル名のテンプレート | 下の「使える項目」を組み合わせて指定。「/」でフォルダを区切れる |
| フォルダの使い方 | フォルダに分けて保存する(初期設定) / フォルダは作らず、フォルダ名をファイル名の前に付ける |
| 日付の基準 | ツイートの投稿日時 / ダウンロードした日時 |
| 連番 | 開始番号(0 / 1)と桁数(1〜3) |
| `{text}` の最大文字数 | ツイート本文の先頭を何文字使うか |
| 画像サイズ | 原寸 / 4096px / 大 / 中 / 小 |
| 動画・GIFも保存する | オフにすると画像だけ保存する |
| 動画の画質 | 最高画質 / 最小サイズ |
| 同名ファイルがあるとき | 連番を付けて残す / 上書き / 毎回確認 |
| 保存先を毎回聞く | 保存のたびに保存ダイアログを出す |
| お知らせ | 保存を始めたとき・終わったときに画面の下に出すか / お知らせに保存先のパスも出すか(初期設定は出さない) |
| 保存済みの表示 | 保存済みのツイートのボタンを緑にする |

### テンプレートで使える項目

| 項目 | 内容 | 例 |
| --- | --- | --- |
| `{user}` | ユーザーID(@の後ろ) | `username` |
| `{id}` | ツイートID | `2117123456789012345` |
| `{index}` | 画像の連番 | `0` |
| `{YYYY}` `{MM}` `{DD}` | 年・月・日 | `2026` `11` `02` |
| `{hh}` `{mm}` `{ss}` | 時・分・秒 | `14` `15` `41` |
| `{text}` | ツイート本文の先頭(URLは除去) | `サンプルのツイート本文` |

Windowsで使えない文字(`\ / : * ? " < > |`)は `_` に置き換わります。

## インストール

### Chrome / Edge

1. このリポジトリをダウンロードして展開する
2. `chrome://extensions`(Edgeは `edge://extensions`)を開き、「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で `chrome` フォルダを選ぶ

### Firefox(140以降)

署名済みのファイルを配っています。自動更新にも対応しています。

1. [Releases](https://github.com/kako774/X-Image-Downloader/releases/latest) から、最新の `x-image-downloader-<バージョン>.xpi` をダウンロードする
2. ダウンロードした `.xpi` を Firefox の画面にドラッグする(または、ファイルを Firefox で開く)
3. 確認が出たら「追加」を押す

新しい版が出ると、Firefox が自動で入れ替えます(Firefox が更新を確認するのは、1日に1回ほどです)。

ソースコードから試したいとき(Firefoxを閉じると消えます):

1. `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」で `firefox` フォルダの `manifest.json` を選ぶ

画像付きツイートに保存ボタンが出ないときは、`about:addons` の拡張機能の「権限」で x.com へのアクセスがオンになっているか確認してください。

### 新しい版を出すとき(Firefoxの自動更新)

`firefox/manifest.json` の `update_url` は、このリポジトリの `updates.json` を指しています。新しい版を出すときは、次の手順で自動更新に載せます。

1. `manifest.json` のバージョンを上げて、`firefox` フォルダの中身をzipにする
2. [addons.mozilla.org](https://addons.mozilla.org/developers/) に「非公開(自己配布)」で出して、署名済みの `.xpi` を受け取る
3. GitHubのReleasesに、タグ `v<バージョン>` で `.xpi` を `x-image-downloader-<バージョン>.xpi` の名前で載せる(AMOからダウンロードしたファイルは、名前を変えても署名は壊れません)
4. `updates.json` の `updates` に、次の1件を足して push する(`update_hash` は `sha256:` から始まる `.xpi` のハッシュ。任意だが付けると安全)

```json
{
  "version": "1.4.4",
  "update_link": "https://github.com/kako774/X-Image-Downloader/releases/download/v1.4.4/x-image-downloader-1.4.4.xpi",
  "update_hash": "sha256:..."
}
```

Firefoxは定期的に `updates.json` を見て、新しい版があれば自動で入れ替えます。AMOで公開する場合は、`update_url` を消してください。

## フォルダ構成

- `chrome/` … Chrome / Edge 用(Manifest V3、service worker)
- `firefox/` … Firefox 用(Manifest V3、event page)
- `updates.json` … Firefoxの自動更新用の情報

2つのフォルダのJavaScript・CSS・HTML・アイコンは同じ内容で、違うのは `manifest.json` だけです。
コードを直すときは、両方のフォルダに同じ変更を入れてください。
